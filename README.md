# CrimeLens AI

## 🚀 Project Overview

CrimeLens AI is a full-stack web application that analyzes historical crime data, visualizes crime trends, identifies hotspots, and forecasts future crime patterns using Machine Learning.

---

## 🎯 Objectives

- Visualize crime statistics
- Display crime hotspots on an interactive map
- Analyze historical crime trends
- Forecast future crime rates
- Provide an intuitive analytics dashboard

---

## 🛠 Tech Stack

### Frontend
- React
- Tailwind CSS

- Recharts

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

- Python
